
SYSTEM REFACTOR TODO LIST

GLOBAL GOALS
    • Mutation must remain pure and mechanical.
    • Services must not construct runtime patches.
    • Patch construction must be centralized.
    • Capability resolution and runtime mutation must follow the same canonical system.
    • Intent must be the source of default behavior and policy configuration.
    • Executor remains the primary orchestrator.

------

RUNTIME MUTATION LAYER (system/runtime/mutator.lua)

Goals
    • Mutator must only apply changes to runtime objects.
    • Mutator must not derive fields or perform domain logic.

Tasks
    • Remove Formula usage from mutator.
    • Remove price derivation logic (ea_price, lf_price, batch_price).
    • Remove rounding logic.
    • Ensure mutator only assigns fields from patches to runtime objects.
    • Ensure mutator supports patch lists.
    • Ensure mutator does not validate patch meaning.
    • Confirm mutator does not access schema or domain logic.

Result
    • Mutator becomes a pure state writer.
